# Release manifest

This manifest lists every product file in the curated HideMark release. The repository's Git
tree is authoritative; generated bytecode, local mappings, input documents, and runtime state are
not included.

| File | Purpose and release rationale |
| --- | --- |
| `.dockerignore` | Limits Docker build context to files needed to build the application. |
| `.github/workflows/ci.yml` | Runs repository checks on public source and synthetic test data. |
| `.gitignore` | Keeps local data, mappings, generated files, and environment files out of Git. |
| `CHANGELOG.md` | Describes the initial HideMark product release. |
| `Dockerfile` | Builds the application image from repository source and pinned requirements. |
| `LICENSE` | States the project's MIT license and copyright holder. |
| `Makefile` | Provides documented build, run, test, and maintenance entry points. |
| `NOTICE.md` | Records third-party notices required by shipped dependencies. |
| `README.md` | Documents verified product behavior, setup, use, and limitations. |
| `SECURITY.md` | Documents the threat model, reporting path, and security limitations. |
| `anon.py` | Implements the core detection, anonymization, and CLI behavior. |
| `catalogs/README.md` | Explains the public curated dictionaries and their format. |
| `catalogs/free-mail-domains.txt` | Public domain classification data used by detection. |
| `catalogs/it-cities.txt` | Public Italian city-name data used by detection. |
| `catalogs/products.txt` | Public product-name dictionary used by detection. |
| `catalogs/vendors.txt` | Public vendor-name dictionary used by detection. |
| `composition.py` | Implements multi-document composition and private manifests. |
| `convert.py` | Implements optional document conversion through the pinned converter. |
| `deanon.py` | Restores reviewed outputs using local mapping files. |
| `docxfill.py` | Builds a DOCX from Markdown while retaining the reference document's style and TOC field. |
| `docxstruct.py` | Reports a DOCX structure without exposing body prose or absolute input paths. |
| `docker-compose.model.yml` | Optional local-model service configuration, bound to loopback. |
| `docker-compose.yml` | Application and slim container definitions with loopback port bindings. |
| `docker-entrypoint.sh` | Validates container startup configuration and launches the service. |
| `docs/DESIGN.md` | Describes application data flow and security boundaries. |
| `docs/RELEASE-MANIFEST.md` | Records the file-by-file scope and rationale for this release. |
| `docs/brand/banner.svg` | Provides the HideMark project banner as source SVG. |
| `git-hooks/pre-commit` | Prevents unsafe Git filters from being used with the repository. |
| `mcp_anon.py` | Implements the stdio MCP interface and request limits. |
| `pdfout.py` | Implements generated PDF output for the supported workflow. |
| `requirements-anydoc.txt` | Pins optional conversion dependencies with hashes. |
| `scripts/anon-home-backup.sh` | Backs up and verifies the local mapping store. |
| `scripts/bench-check.py` | Measures the scanner using generated synthetic content. |
| `scripts/bench-index.py` | Measures dictionary indexing with generated synthetic data. |
| `scripts/bench-scan.py` | Measures scanning with generated synthetic inputs. |
| `scripts/bench-suggest.py` | Measures the optional suggestion interface against a configured local endpoint. |
| `scripts/check-container-fresh.py` | Verifies that the running container serves the current build. |
| `scripts/check-doc-numbers.py` | Checks selected documented limits against implementation values. |
| `scripts/convert-fidelity.py` | Checks conversion fidelity using generated inputs. |
| `scripts/coverage.py` | Runs the coverage gate against the test suite. |
| `scripts/fetch-suggest-model.sh` | Retrieves the optional model after checksum verification. |
| `scripts/fp-sweep.py` | Evaluates false-positive behavior on generated inputs. |
| `scripts/install-git-hooks.sh` | Installs the repository's pre-commit safety hook. |
| `scripts/mutate.py` | Checks that selected defects are caught by named tests. |
| `scripts/pin-converter.py` | Creates or verifies the pinned optional converter environment. |
| `scripts/recall-sweep.py` | Evaluates detection recall on generated inputs. |
| `scripts/smoke-docker.sh` | Builds and exercises the container endpoints. |
| `scripts/tag-collision.py` | Checks placeholder tag allocation for collisions. |
| `suggest.py` | Implements the optional loopback-only suggestion interface. |
| `tests/corpus.py` | Defines synthetic test input data and expected detection cases. |
| `tests/SYNTHETIC-DATA.md` | Documents fixture provenance and realistic-shaped vectors retained for tests. |
| `tests/test_anon.py` | Tests the engine with generated and explicitly synthetic fixtures. |
| `tests/test_backup.py` | Tests mapping-store backup and restore behavior in temporary directories. |
| `tests/test_composition.py` | Tests composition using temporary synthetic documents and maps. |
| `tests/test_dictionary_classification.mjs` | Tests public dictionary classifications. |
| `tests/test_docxfill.py` | Tests DOCX generation, reference preservation, and TOC field handling with synthetic documents. |
| `tests/test_docxstruct.py` | Tests DOCX structure reporting and comparison with synthetic documents. |
| `tests/test_git_guard.py` | Tests repository Git-filter safeguards in temporary repositories. |
| `tests/test_mcp.py` | Tests the MCP interface with synthetic protocol messages. |
| `tests/test_suggest.py` | Tests suggestions using synthetic input and local test servers. |
| `tests/test_smoke_docker_diagnostics.py` | Tests Docker smoke diagnostics and safe cleanup with a fake Docker CLI. |

| `web/index.html` | Provides the browser UI document. |
| `web/server.py` | Implements the loopback-only web server and API. |

Excluded categories include Git metadata and history, local Pi configuration and skills, runtime
containers and volumes, environment files, local mappings, real input/output documents, caches,
logs, generated bytecode, screenshots, temporary files, and untracked source-checkout material.
